# 🎧 Techno & EDM Festival

Landing page para un festival de música electrónica (Techno & EDM), con line up, galería y venta de boletos.

## 📋 Descripción

Sitio web de una sola página que presenta la información de un festival ficticio de Techno & EDM en CDMX, México. Incluye un video de fondo en el hero, información del evento, cartel de artistas por día y escenario, galería de imágenes y planes de boletos disponibles.

## ✨ Características

- **Hero con video de fondo** — autoplay en loop con múltiples formatos (`mp4`, `ogv`, `webm`) para compatibilidad entre navegadores.
- **Sección "Sobre el festival"** — presentación del evento con imagen y descripción.
- **Line Up** — cartel de artistas organizado por día (Viernes y Sábado) y por escenario (Techno / EDM), con horarios.
- **Galería** — sección dedicada a imágenes del evento.
- **Boletos** — tarjetas de precios con los beneficios incluidos en cada pase (1 día / 2 días).
- **Diseño responsive** — pensado para adaptarse a distintos tamaños de pantalla.

## 🛠️ Tecnologías

- HTML5
- CSS3 (compilado en `build/css/app.css`)
- JavaScript (compilado en `build/js/app.js`)
- Google Fonts (Montserrat)


## 🚀 Uso local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/LuisOrlando-code/FESTIVAL-DE-MUSICA.git
   ```
2. Entra a la carpeta del proyecto:
   ```bash
   cd FESTIVAL-DE-MUSICA
   ```
3. Abre `index.html` en tu navegador, o sirve el proyecto con un servidor local.
